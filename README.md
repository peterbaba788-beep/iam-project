# Identity and Access Management (IAM) System Deployment

## Project Overview

This project focuses on planning the deployment of an Identity and Access Management (IAM) system to strengthen access control and support cybersecurity improvements.

The project is managed as part of an IT Project Management group assignment. GitHub is used to organise project documentation, track changes, maintain version history and support collaboration between team members.

## Project Objectives

- Define the project scope, objectives and deliverables.
- Develop a Work Breakdown Structure (WBS) and project schedule.
- Identify project risks and develop mitigation strategies.
- Establish processes for managing project changes and issues.
- Allocate responsibilities among team members.
- Maintain project documentation using version control.

## Repository Structure

| Directory or File | Purpose |
|---|---|
| `docs/` | Project planning and management documentation |
| `scripts/` | Supporting Markdown files and project registers |
| `change-logs/` | Record of approved and completed project changes |
| `config/` | Relevant configuration documentation |
| `test/` | Test planning and supporting test documentation |
| `README.md` | Project overview and repository guide |

## Configuration Management

The group uses GitHub branches, commits and pull requests to manage changes to project artefacts. Proposed changes can be reviewed before being merged into the main branch.

## Team Collaboration

Team members contribute to project documentation and review changes relevant to their assigned responsibilities.
